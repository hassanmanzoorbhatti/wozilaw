## Goal

Flip the site from the dark maroon theme to a bright theme with `#F6F7F8` as the section background — keeping every layout, section, eyebrow, heading, subheading, description, button, image, column, container, border and mobile behaviour exactly as it is. Only colour values change.

## Colour mapping

The page already routes almost all colour through six tokens in `src/styles.css`. Retoning those tokens flips the whole site consistently:

| Token | Now (dark) | New (bright) | Used for |
|---|---|---|---|
| `--color-clause-bg` | `#140009` | `#F6F7F8` | all section/page backgrounds |
| `--color-clause-border` | `#4d0020` | `rgba(0,0,0,0.10)` | grid lines, dividers, card borders |
| `--color-clause-heading` | `#f2ede0` | `#14181C` (ink) | headings, stat numbers |
| `--color-clause-cream` | `#ecebd8` | `#2B3238` | body copy, nav links, footer |
| `--color-clause-muted` | `#b3a595` | `#5B646C` | secondary paragraphs |
| `--color-clause-pink` | `#eb006a` | kept as-is | accent: eyebrows, dots, primary buttons, active tabs |

Accent stays the original pink so the brand signal is unchanged; button text on the pink fill switches to white-ivory so it stays legible on light.

## Hardcoded values to convert (in `src/routes/index.tsx`)

These are the only places colour is written inline rather than via a token:

- Nav bar `bg-[rgba(20,0,9,0.35)]` → light translucent (`rgba(246,247,248,0.7)`), blur kept.
- Mobile menu overlay `rgba(20,0,9,0.55)` → light translucent equivalent.
- CTA section and testimonial card `bg-[#140009]` → `bg-clause-bg` (or a very slightly whiter surface `#FFFFFF` for cards so they lift off the page — flagged below).
- Zigzag SVG strokes `#4d0020` → light-theme line colour.
- Promise-section icon tiles `bg-[#1e000d]` and icon colour `#8a4a5c` → light tile + mid-grey icon.
- Corner-notch squares `bg-[#4d0020]` / `bg-[#140009]` → matched to the new border and background colours.
- `hover:bg-white/5` on footer social buttons → `hover:bg-black/5`.

## Other files touched

- `src/styles.css`: token values above, plus the scrollbar colours (`html { scrollbar-color }` and the `::-webkit-scrollbar-*` rules) retoned to light.
- `src/components/motion/Preloader.tsx`: overlay already uses `bg-clause-bg`, so it flips automatically — no change needed beyond verifying contrast of the wordmark.
- `src/components/motion/CustomCursor.tsx`: dot keeps the pink accent; opacity nudged so it reads on a light background.

## Card surfaces

On a fully flat `#F6F7F8` page, bordered cards (testimonials, news, service panels) would read as invisible boxes. Plan: keep their 1px border as the primary definition, and give card interiors pure white `#FFFFFF` so they separate subtly — no shadows, no radius change, same padding and sizes. If you'd rather everything be flat `#F6F7F8` including cards, say so and I'll drop the white surfaces.

## Not changing

Typography, font families, sizes, `clamp()` scales, spacing, borders' widths, imagery, copy, all motion/animation behaviour, mobile breakpoints and layout.

Screenshot desktop (1440) and mobile (393) top-to-bottom, checking every section reads on the light background, text contrast is comfortable, borders are visible but subtle, buttons and active tab states still stand out, and no console errors.
