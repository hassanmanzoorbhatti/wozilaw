
## 5. One thing to check before deploying to Vercel

This project was generated by Lovable and uses `@tanstack/react-start` (SSR) with
Nitro as the server build tool. Nitro's preset in this repo currently defaults to
Cloudflare (set inside `@lovable.dev/vite-tanstack-config`, per the comment in
`vite.config.ts`) rather than Vercel. `npm run build` completes successfully as-is,
but if the Cloudflare-targeted output doesn't deploy cleanly on Vercel, you may
need to set Nitro's preset to `vercel` (commonly via a `NITRO_PRESET=vercel`
environment variable in your Vercel project settings, or a small `vite.config.ts`
override) — I didn't change this since I can't test an actual Vercel deploy from
here. Worth flagging to Lovable support if you hit it.
